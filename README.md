# NanoBanana Personal

내 API 키로 쓰는 AI 이미지 생성 앱이에요 (Windows 전용).
Google Gemini(나노바나나), OpenAI GPT Image, BytePlus Seedream 을 한 화면에서 씁니다.

## 받기

**[NanoBanana-Personal.exe 받기](https://github.com/productionkhu-tech/freewill-nanobanana-personal/releases/latest/download/NanoBanana-Personal.exe)**

- 설치는 필요 없어요. 받은 파일을 원하는 폴더(예: 바탕화면)에 두고 실행하면 됩니다. `Program Files` 아래는 피해 주세요 — 업데이트가 안 돼요.
- 처음 실행하면 "Windows의 PC 보호" 창이 뜰 수 있어요. **추가 정보 → 실행** 을 누르면 됩니다.
- 새 버전은 앱을 껐다 켜면 저절로 설치돼요.

## 키 넣기

앱 왼쪽 위 **내 키** 에서 넣어요. 가진 키만 넣어도 되고, 키가 없는 곳의 모델은 메뉴에서 잠겨요.
키를 넣으면 앱이 무료로 확인한 뒤(이미지를 만들지 않아요) 저장해요.
오른쪽 위 점이 회사마다 키 상태를 실시간으로 보여 줘요: 초록 = 준비됨 · 노랑 = 확인 전 · 빨강 = 거절됨 · 회색 = 키 없음. 점을 누르면 '내 키' 창이 열려요.

| 어디 | 키 만드는 곳 | 미리 알아 둘 것 |
|---|---|---|
| Google AI Studio (Gemini) | https://aistudio.google.com/apikey | 이미지 모델은 Google 계정에 결제를 연결해야 쓸 수 있어요 |
| OpenAI (GPT Image) | https://platform.openai.com/api-keys | GPT Image 는 조직 인증이 필요해요: https://platform.openai.com/settings/organization/general |
| BytePlus (Seedream) | https://console.byteplus.com/ark/region:ark+ap-southeast-1/apiKey | 쓰려는 Seedream 모델을 콘솔에서 '활성화' 해야 해요 |

## 알아 두기

- **요금은 각자의 계정에 청구돼요.** 앱은 돈을 받거나 사용량을 모으지 않아요.
- **키는 이 PC 안에만 있어요.** 윈도우 계정으로 암호화해 저장하고(다른 계정·다른 PC 에선 못 열어요), 화면에는 끝 네 글자만 보여요.
- **이미지와 키 확인은 이 PC 에서 각 회사(Google · OpenAI · BytePlus)로 바로 가요.** 그 밖의 곳으로는 아무것도 보내지 않아요. 업데이트 확인만 GitHub 에 물어요.
- 다른 프로그램(MCP·에이전트 등)이 이 앱으로 생성 요청을 보낼 수는 없어요.
- 윈도우 10/11 전용이에요.
